# V6.22 — Professional Screening Result UI

Based directly on V6.21.

The raw JSON Screening result is replaced with a recruiter-friendly result card:
- Score / 100
- Match status badge
- Assessment Summary
- Strengths
- Areas to Review
- Skills Match chips
- Profile Snapshot
- Recommendation
- Professional error state

The API/data flow, authentication, R2, D1, bulk upload and extraction logic are
not changed by this UI release.
